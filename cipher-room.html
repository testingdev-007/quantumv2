✅ Programming: What's a variable?

        
A named box holding a value you can change. Nothing more mysterious than that.

✅ Programming: Two kinds of loop

        
In the Vault Heist you used a counted loop — "do this six times" — because you knew the number.
the rest of it
Here you used the other kind: "keep going until it works." Your program had no idea whether the answer was at key 3 or key 25, so it could not count. It just kept trying and stopped the moment it succeeded. Between them, those two cover almost every loop ever written.

      

      

        
✅ Programming: What's a function?

        
A named recipe you can run whenever you like. Write it once, use it forever, and never think about the insides again.
the rest of it
password_maker took four pieces of information — some text, a True/False, more text and a number — did its job, and handed you back a password. Almost everything in real software is functions calling other functions.

      

      

        
✅ Quantum: Why won't long passwords stay safe forever?

        
Classical brute force takes exponentially longer as keys get longer — a 128-bit key would take a classical computer far longer than the universe has existed.
the rest of it
A quantum computer needs roughly the square root of that effort — which is why banks are switching to longer, quantum-resistant keys now. But quantum isn't only the threat: entangled keys (QKD) make eavesdropping self-announcing, the same "spooky" link from the Twin Vaults turned into a genuine defense.
